# landing-site

The Scribe Sheets umbrella landing page — lives at the bare root domain
(`scribe-sheets.com`). Introduces the brand, links out to the five per-game
sites, and lets a visitor register a shared account against the `nexus-core`
backend. Game-specific character data and sheets live in the sibling apps
(`godbound-site`, `mythras-site`, `witcher-site`, `mutants-and-masterminds`,
`my-app`), not here.

## Developing

```sh
npm install
npm run dev
```

## Building

```sh
npm run build
```
